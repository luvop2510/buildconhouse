# Kitchen details and existing references — 26 October 2026

Each Kitchen stage now separates saved details into bordered label/value cells. Order confirmation, actual pending/confirmed status, and the currently approved quotation are independent fields. The save indicator has its own bordered area. Early stages and commercial stages use the same pattern; stage navigation and business commands remain unchanged.

The shared reference picker opens with existing architects and interior designers together. Search matches name, company/studio or stable reference code. Loading, empty results and a failed directory read have distinct feedback and explicit retry. The list renders 25 choices at a time with Show more. The quotation-specific picker follows the same behavior and selects the result's actual type. These cover customer creation/editing, Walk-ins/Follow-ups, Kitchen intake and saved leads, Furniture quotations, and Sanitary quotations. Ground Floor tile selections/quotations now expose the shared picker in both desktop and phone editors.

Tiles reference edits are explicit. Ordinary saves omit reference fields, preserving archived identities and legacy text. Since quotation creation inherits customer attribution, the first explicit document choice is patched before the editor declares it saved; failed patch retry retains the created document ID. Newer choices remain dirty during a pending save. Document-scoped picker lifetimes reject delayed creation responses after navigation. A same-customer backend snapshot refresh updates customer name/phone while preserving document attribution; changing customers still inherits the new customer's reference, and explicit selections retain directory validation and floor authorization. No schema or data migration is added.
