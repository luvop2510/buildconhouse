# Kitchen PDF usability and Railway startup — 26 October 2026

The Kitchen queue now uses the compact list at every width. Retired table/board bookmarks keep their stage filters. No anonymous readiness call or one-minute wake screen precedes account restoration, login or floor access; authoritative identity recovery, floor generations, the mounted navigator and ordinary transport timeouts are retained.

CAD progress derives its status on both the server and the form: 0 is Not Started, 1–99 is In Progress, 100 is Completed. CAD receipt separately determines readiness. The supplied Kitchen specification is the field/workflow reference; the user's explicit corrections that lead/visit are fine and that stage navigation remains manual are preserved. Customer-requested revision counts are read-only and only recorded revision requests increment them. Design presentation can select an optional private uploaded document.

Quotation entry uses private project documents and no longer offers an HTTPS field or link. Empty document libraries direct users to the working Documents upload instead of a disabled selector. Order confirmation includes the final amount; changes retain the original quotation and require owner authorization plus explicit customer approval. Confirmed dates/notes can be corrected with chronology and before/after history, retained stale drafts cannot overwrite newer details, and confirmation documents can be replaced while retaining both files and their history. Date input padding is bounded for narrow viewports. Ordinary shared text fields retain focus on Enter, preventing keyboard/chrome restoration from shifting the page; explicit submission and blur behavior remain unchanged. Existing advance, status and amended-amount controls remain available.

Sales Data → Architects and Interior Designers now includes an editable directory with company/contact/address and linked clients. New references are reusable across authorized floors. Existing private references retain their IDs and attribution, and become shared only when the owner saves them in the directory. Customer/order/revenue reads remain floor scoped; private reference ID authorization preserves existing accessible-floor behavior. Directory updates require owner access and a matching saved version. No database migration or business-record rewrite is needed.

The existing deployed baseline was source 92bf1c81 on both Vercel and Railway. Its prior release evidence identified Railway Under Attack Mode blocking server-to-server API calls; that mode was already disabled before this change. A fresh live health read succeeded, so this release does not claim to reproduce an ongoing configuration failure. The source removes the unnecessary startup gate and retains safe retry/idempotency for writes.
