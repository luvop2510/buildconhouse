The quotation template derives from the user-supplied September 2026 Grohe
workbook (source SHA256
`14c5109cd52e7de76540c33be5d73d2d539b409b1dd7dceb79dd36afdd7bb86a`).

The original styles, rich text labels/terms, widths, hidden offer columns,
merged ranges, row heights, company/brand artwork and printer settings are
retained. Sample customer/product cells, product pictures, unused shared
strings, cached customer values, author metadata, original local directory and
thumbnail are removed. No customer reference data is shipped to other customers.

The renderer fills the original eight bathroom slots, extending the same row
layout only for larger quotations. Original per-product arithmetic is retained
as explicit formulas with current cached results. Quantity sums include every
product row (the reference accidentally stopped at row 18). Effective discounts
include the agreed selling-price difference from MRP and the app's complete
discount cascade. The special-offer summary sums current room totals. PO Final
additional costs use the same row layout in an additional room. Product photos
come from the same exact-product, floor-checked image resolution and bounded
storage fetcher as PDF exports.
